# WinRust: планы

English version: [ROADMAP.md](ROADMAP.md) | Português: [ROADMAP.ptbr.md](ROADMAP.ptbr.md)

У каждого пункта указано, насколько он проверен: **тесты** (юнит-тесты), **собрано** (компилируется, не запускалось), **запускалось** (руками на живой системе), **сквозная** (полная установка/удаление на живой системе).

## Сделано

### Установщик

- Исправления после ревью (v0.3.0): rs-du хранит список карантина рядом со своим exe (писать туда может только администратор), `payload\` двумя уровнями выше берётся только из `target\release`, rtaskmgr и rust-explorer сохраняют и возвращают чужие настройки диспетчера задач и папок, rust-search сначала возвращает поиск Windows и только потом удаляет свои файлы, DiagTrack оставлен debloat, один разбор вывода `reg query` с тестом. _тесты, собрано_
- Один `plugin-launcher.exe`, в который вшиты все плагины (распаковка в Program Files, не в %TEMP%), статический CRT, тёмное окно на Win32/GDI. _запускалось_
- «Install WinRust» ставит недостающее по порядку (topbar раньше rust-explorer), когда всё стоит, обновляет; «Удалить всё» удаляет в обратном порядке. _собрано_
- Сбой установки откатывает свои изменения (кроме обновления рабочей копии); исходные значения (WSearch, строка поиска, настройки Проводника, службы) сохраняются в `HKLM\SOFTWARE\plugin-launcher\<плагин>` и возвращаются при удалении; несмертельные ошибки пишутся в `%ProgramData%\plugin-launcher\install.log`. _собрано_
- Точка восстановления перед установкой. _собрано_
- Одна кнопка ставит недостающее **и** обновляет установленное: запуск нового `WinRust.exe` доносит исправления до всех плагинов (v0.2.1). _собрано_
- Командная строка: `list | install <плагин> --yes | update <плагин> | uninstall <плагин> | rollback --yes`, коды выхода 0/1/2; окно и командная строка вызывают одни и те же функции. Запускались только команды, которые ничего не меняют. _запускалось (частично)_
- `update` и `scripts\update-plugin.ps1`: переустановка из `payload\` на диске без пересборки установщика. _запускалось_
- Английский по умолчанию, переключатель Русский/English в установщике и в меню панели; выбор хранится в `%ProgramData%\WinRust\lang.txt`. _тесты_
- Устройство кода: один cargo workspace; установщик разделён на `install/` (файл на плагин), `cli.rs`, `ui.rs`; общий crate `winrust-common` (переключатель языка, чтение MFT); один список `payload.txt` для сборки и скриптов; CI на GitHub Actions. _тесты_

### Плагины

- **rust-search**: служба поиска по NTFS + Alt+Space; отключает WSearch, блокирует SearchHost.exe, прячет строку поиска. Правый клик по результату: переименовать, в корзину, «удалить навсегда + почистить реестр» (сканирование → подтверждение → удаление; реестр сначала сохраняется в `%LOCALAPPDATA%\rs-search\registry-backups\*.reg`). _тесты, запускалось_
- **rtaskmgr-win32**: заменяет диспетчер задач через IFEO-Debugger (`taskmgr.exe` не трогается); при панике пишет `%APPDATA%\rtaskmgr\crash.log` и открывает настоящий Taskmgr. _тесты, запускалось_
- **topbar**: нижняя панель в стиле Windows 11 вместо панели задач; `topbar.exe --restore` возвращает панель задач. Вместе с ним ставятся хоткеи reshell, rs-du, блок профиля PowerShell (`src/install/profile.ps1`, Windows PowerShell 5.1 и pwsh 7). _запускалось; блок профиля только на временном профиле_
- **Страховка reshell**: если topbar не запущен, а панель задач скрыта, два раза подряд (~10 с), запускает `topbar.exe --restore`. _тесты; сценарий «убить topbar» не проверялся_
- **Хоткеи reshell**: Win+D (показать рабочий стол) и Win+I (Параметры) работают без Проводника, как Win+E (v0.2.1). _запускалось_
- **Стили** (v0.3.0): шестерёнка в левом краю панели переключает Обычный / Терминал / Плавающий док / Тайлинг; панель, rust-explorer и окно поиска перекрашиваются сразу (широковещательное сообщение, `%ProgramData%\WinRust\style.txt`). Док не занимает места на экране и уезжает из-под развёрнутых окон; Тайлинг ставит панель наверх и умеет раскладывать окна плиткой. _запускалось_
- **Вид topbar** (v0.3.0): значок сети рисуется сам (дуги Wi‑Fi по сигналу, крестик без сети, «!» без интернета, по данным Windows о подключении); новая панель Wi‑Fi (статус, карточка подключённой сети с отдельной кнопкой «Отключиться», сохранённые и открытые сети, строки появляются по очереди); меню только из текста с подсказками клавиш; выбор языка ввода (левый клик по ENG/RUS); трей проявляется с анимацией, стрелка поворачивается. _запускалось_
- **rust-explorer**: файловый менеджер (вкладки, иконки, копирование/вставка/удаление через IFileOperation, контекстное меню, перетаскивание), рисует рабочий стол, отключает Проводник как оболочку через `rs-shell --overlay` (не позже 90 с после входа: Windows 26300 больше не пишет отметки автозагрузки, которых он ждал, v0.2.1), урезает службы. _тесты, запускалось_
- **rs-du**: чистильщик диска (анализ MFT, кеши, `target`/`node_modules`, корзина, карантин на 30 дней), запускается из меню панели. _тесты_
- **wiztree**: карта занятого места по MFT. _тесты (только раскладка); на живом диске не запускался_
- **photoview**: просмотр фото на WIC, поворот по EXIF, пункт «Открыть с помощью». _запускалось; EXIF-ориентации 5 и 7 не проверялись_
- **debloat**: службы и политики (телеметрия, Copilot, Recall, реклама, фоновый Edge), старые значения в `%ProgramData%\winrust-debloat\undo.txt`, `--undo`. _сухой прогон запускался; `--apply`/`--undo` нет_

## Дальше (по порядку)

1. **Проверка на чистой Windows 11 в виртуалке**: установка, удаление, откат, перезагрузка, по каждому плагину. На другой машине пока ничего не проверялось.
2. **Один журнал отката для всех плагинов**: каждое изменение (значение реестра, служба, файл) записывается как «было → стало» до того, как сделано; удаление и откат проигрывают журнал назад. Заменяет ручной uninstall каждого плагина. Сначала нужен шаг 1 и миграция для установок текущей версии.
3. **Реестр через Win32 API** (`RegGetValueW`/`RegSetValueExW`) вместо запуска `reg.exe` и разбора его вывода.
4. **Релизы**: SHA-256 рядом с exe, версия в окне, проверка обновлений.
5. **Подпись кода** (убирает предупреждение SmartScreen и часть ложных срабатываний антивирусов).
6. **Профиль PowerShell**: по желанию ставить rg/fd/bat/eza/zoxide через winget (галочка в настройках topbar).
7. **chrome-rs**: настоящая установка, когда браузер будет готов (см. `plugins/chrome-rs/ROADMAP.md`).
8. **Win+S / кнопка «Пуск»** открывают rust-search вместо поиска Windows (рискованно, отдельное решение).
9. **Не-NTFS диски** в rust-search (сейчас пропускаются).

## Известные ограничения

- Системные компоненты отключаются или обходятся (обратимо), а не удаляются: удаление `taskmgr.exe` или поиска Windows сломало бы защиту системы.
- Нужны права администратора.
- Win+S и «Пуск» по-прежнему открывают поиск Windows.
